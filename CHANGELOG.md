# Changelog

## 1.0.0

- First release of Valuable Parry.
- E creates a short ParryIntent while holding a ValuableObject.
- Harmony prefix on HurtCollider.PlayerHurt intercepts supported melee hits.
- Coverage, minimum size, and size/mass capacity checks.
- Freeze → absorption → overload → detonation timeline.
- Vanilla PhysGrabObjectImpactDetector.DestroyObject sacrifice path.
- Player tumble + enemy freeze/knockback scaled by attack energy.
- Procedural absorption/detonation VFX and audio.
- Host-side destruction/freeze; remote clients play the visual sequence.
- Optional debug overlay/gizmos via config only (no hotkeys; F8 belongs to Admin Menu).
